# Aventric website

Static landing page for Aventric (no build step). Open `index.html`, or serve the folder:

    python3 -m http.server 8000

- `index.html` – content
- `styles.css` – brand tokens (navy `#19279A`, ink `#0D0D14`, white, Poppins) and layout
- `site.js` – motion: intro, hero lattice, tickers, pinned scroll scenes
- `assets/logo/` – Aventric icon (navy, white, favicon), traced from the brand logo PDFs

## Hosting

Served by GitHub Pages from the `main` branch at https://aventric.io (see `CNAME`).
