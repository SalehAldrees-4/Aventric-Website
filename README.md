# Aventric website

Static landing page for Aventric (no build step). Open `index.html`, or serve the folder:

    python3 -m http.server 8000

- `index.html` – content
- `styles.css` – brand tokens (navy `#19279A`, ink `#0D0D14`, white, Poppins) and layout
- `site.js` – motion: intro, hero lattice, tickers, pinned scroll scenes
- `assets/logo/mark.svg` – **placeholder** icon; replace with the real Aventric icon
